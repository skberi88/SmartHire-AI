# SmartHire AI

**SmartHire AI** is a full-stack recruitment and hiring platform designed to streamline the hiring process for applicants, employers, and administrators. The platform provides secure role-based authentication, job management, application tracking, and resume handling, while being architected for future AI-powered recruitment features.

## 🚀 Features

### 👨‍💼 Applicant

* Secure registration and login
* Browse available job opportunities
* Apply for jobs
* Upload and manage resumes
* Track submitted applications
* Manage profile information

### 🏢 Employer

* Secure registration and login
* Create and manage job postings
* View applicants for posted jobs
* Review candidate profiles and resumes
* Manage hiring workflows

### 🛡️ Admin

* Platform-wide dashboard
* User management
* Employer management
* Job monitoring and moderation
* Application analytics and reporting

### 🔐 Authentication & Security

* JWT-based authentication
* Role-Based Access Control (RBAC)
* Protected routes and APIs
* Secure password storage

## ⚙️ Installation & Setup

### Clone Repository

```bash
git clone https://github.com/your-username/SmartHire-AI.git
cd SmartHire-AI
```

### Backend Setup

```bash
cd backend
```

Configure your MySQL database in:

```properties
application.properties
```

Run the Spring Boot application:

```bash
mvn spring-boot:run
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend will run on:

```text
http://localhost:5173
```
